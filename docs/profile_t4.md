# Profil T4 — lima temuan (D11, langkah 1a)

> Jalankan dulu: `python -m pipeline.profile --topic t4`
> Perintah itu MENULIS ULANG berkas ini dengan tabel profil mentah dari delapan berkas T4.
> Jadi urutannya: jalankan profilernya, lalu tulis lima temuanmu **di bawah** hasilnya.
>
> Aturannya satu: temuan tanpa angka hanyalah pendapat. Setiap baris wajib punya angka,
> menyebut tabelnya, dan satu kalimat kenapa angka itu penting untuk pertanyaan proyek.
> Dua temuan wajib ada: satu soal **waktu**, satu soal **identitas**.
